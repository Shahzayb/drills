# Tech Context

Layout and what the apps are: `systemPatterns.md`. This file is how to work with them.

## Commands

Root scripts run both apps through Turborepo: `pnpm dev`, `pnpm build`, `pnpm lint`, `pnpm test`, plus `pnpm dev:backend` / `pnpm dev:frontend`. For single-app work run from that app's directory instead — more direct, and it skips turbo's task-graph overhead.

- **Backend** (`apps/backend`): `pnpm run start:dev` (watch), `pnpm run build`, `pnpm run lint`, `pnpm run format`, `pnpm run test` (jest unit, `*.spec.ts` under `src`), `pnpm run test:cov`, `pnpm run test:e2e`. One file: `pnpm exec jest src/app.controller.spec.ts`. By name: `pnpm exec jest -t "pattern"`.
- **Frontend** (`apps/frontend`): `pnpm run dev`, `pnpm run build`, `pnpm run start`, `pnpm run lint`.

## Constraints and gotchas

- **Ports are deliberately split** — override with `PORT=<n>` for the backend, `-p <n>` or a `PORT=<n>` prefix for `next dev`.
- **Next's `PORT` cannot come from `.env`** — the server binds before env files load.
- **Next.js 16 has breaking API, convention, and file-structure changes** from what's likely in training data. Check the bundled docs at `apps/frontend/node_modules/next/dist/docs/` — resolve relative to `apps/frontend`, since `next` may not be hoisted to the root — before writing frontend code, and heed deprecation notices.
- **`apps/frontend/AGENTS.md`** is regenerated by `next dev` and pulled in by `apps/frontend/CLAUDE.md` via `@AGENTS.md`. Commit it rather than stripping it from diffs.

## Workflow hooks

Configured in `.claude/settings.json`; scripts in `.claude/hooks/`. All advisory — none block.

- **SessionStart** (`startup`/`clear`/`compact`) — injects `activeContext.md`. Silent on `resume`, where the transcript already carries it.
- **Stop** — `record-reminder.sh`. Nudges when the tree has source changes but `memory-bank/` has none. Once per session, keyed on `session_id` via a sentinel in `$TMPDIR`.
- **PreCompact** — reminds that `memory-bank/` is the only thing crossing the compaction boundary.
- **PostToolUse** (`Write|Edit`) — `memory-bank-cap.sh`. Reports the line count when a capped file goes over.

To test a hook without a session, pipe its payload in: `echo '{"session_id":"x"}' | bash .claude/hooks/record-reminder.sh`.

## Tooling config

- `.vscode/` — format-on-save with ESLint fix-on-save, per-package `eslint.workingDirectories` (each app has its own flat config), debug configs for backend, frontend, and both together.
- `.npmrc` — `auto-install-peers`, `strict-peer-dependencies=false`, to absorb the two apps' differing dependency trees.
- `.gitattributes` — normalizes line endings, marks lockfiles as generated so they're excluded from diffs.
