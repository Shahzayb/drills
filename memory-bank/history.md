a log, not a summary — for current state and reasoning see `progress.md` and `techContext.md`.

the whole plan to recover — not just the topic. See `SKILL.md` for what that means in practice.

| 2026-08-26 | [drill-10-keyset-pagination](../plans/2026-08-26_drill-10-keyset-pagination.md) | Keyset pagination behind `paging=keyset` + an opaque cursor; **offset kept permanently** as the other arm and the only "jump to page 40". **The curve, org 1, pageSize=50, interleaved:** offset 22.5/17.9/27.4/65.3/**197.4**ms at pages 1/10/100/1000/5000, keyset **3.1-4.3ms flat** — 50.7x at page 5,000 and still climbing. **Export walk, 400 pages: 14.83s vs 1.52s (9.8x)**; full-walk floor 12.3 min vs 1.3 min. **Mechanism, from `rows below the Limit`:** OFFSET is a Limit-node argument, so the scan still emits 250,000 rows for page 5,000 where the cursor emits 50 — and past ~250k the planner abandons the index for a **Seq Scan, 356ms**, so the curve is linear and then steps.
